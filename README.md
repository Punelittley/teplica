# Сайт производителя «Теплицы 76» (Ярославль)

Многостраничный современный, легкий и быстрый сайт с интерактивным калькулятором стоимости, адаптированный под целевую аудиторию садоводов и дачников старшего возраста (40+, женщины, бабушки), с автономной панелью управления.

Готов для бесплатного размещения на **GitHub Pages** и переноса на любой платный хостинг (Beget, TimeWeb, Reg.ru и др.).

---

## 📁 Структура страниц сайта

1. **[`index.html`](index.html)** — **Главная страница и О компании**:
   - Первый экран с теплым фото садовода, УТП производителя и рукописными эмоциональными акцентами.
   - Блок из 6 ключевых преимуществ (собственное производство, оцинкованная сталь, УФ-защита, доставка и монтаж, гарантия до 10 лет, забота о клиентах).

   - Цены и комплектации.
4. **[`gryadki.html`](gryadki.html)** — **Оцинкованные грядки и клумбы**:
   - Забота о здоровье спины для пожилых людей (высота борта 15, 20 и 35 см).
   - Безопасные завальцованные края.
   - Готовые комплекты для теплиц 3х4, 3х6, 3х8 м.
5. **[`dostavka-sborka.html`](dostavka-sborka.html)** — **Доставка и сборка под ключ**:
   - Карта и тарифы доставки по Ярославлю, Рыбинску, Тутаеву, Угличу, Ростову, Переславлю и всем СНТ области.

   - Фундамент из антисептированного бруса 100х100 или грунтозацепы.

6. **[`polikarbonat.html`](polikarbonat.html)** — **Сотовый поликарбонат**:

7. **[`otzyvy.html`](otzyvy.html)** — **Отзывы и фотогалерея**:
   - Реальные отзывы дачников из Ярославля, Рыбинска, Тутаева с фотографиями урожая.
   - Рейтинг 4.9 из 5.0 на основе 124 отзывов.

8. **[`kontakty.html`](kontakty.html)** — **Контакты и выставка**:
   - Адрес выставочной площадки: г. Ярославль, ул. Промышленная, 12.
   - Телефоны, режим работы (без выходных с 8:00 до 20:00).

9. **[`admin/index.html`](admin/index.html)** — **Панель администратора**:
   - Вход по паролю (по умолчанию: `admin76`).
   - Управление заявками и лидами в реальном времени.
   - Экспорт всех заявок в Excel / CSV в 1 клик.
   - Управление ценами в калькуляторе.
   - Управление контактными телефонами, адресом и рекламной акцией.
   - Мгновенные бесплатные уведомления о новых заказах прямо в Telegram.
   - Резервное копирование и экспорт настроек в JSON.

## 🚀 Как опубликовать сайт на GitHub Pages (за 1 минуту)

1. Создайте новый репозиторий на [GitHub](https://github.com/new) (например, `teplici76` или `teplica`).
2. В папке проекта выполните команды:
   ```bash
   git init
   git add .
   git commit -m "Релиз сайта Теплицы 76"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
3. Откройте в вашем репозитории на GitHub вкладку **Settings** -> **Pages**.
4. В разделе **Build and deployment** выберите источник: **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. Через 1-2 минуты ваш сайт будет доступен по ссылке:
   `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`

## ⚙️ Доступ в Панель Управления

- Адрес админки: `/admin/index.html` (или `admin/`)
