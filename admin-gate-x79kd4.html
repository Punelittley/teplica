🚀

Публикация на GitHub Pages в 1 клик

Изменения автоматически обновятся на вашем .com домене за 20–30 секунд
Как подключить один раз (занимает 1 минуту):
  1. Укажите репозиторий в формате имя_пользователя/имя_репозитория (например: myuser/teplica-main).
  2. Сгенерируйте бесплатный токен: в GitHub откройте Settings → Developer settings → Personal access tokens → Tokens (classic), нажмите Generate new token, отметьте галочку repo и скопируйте токен.
  3. Вставьте токен в поле ниже. Он сохранится в вашей админке, повторно вводить не потребуется.

🌐 Привязка домена .com из Reg.ru к GitHub Pages

Пошаговая инструкция для подключения купленного домена на Reg.ru:

1. В личном кабинете Reg.ru в разделе «DNS-серверы и управление зоной»:

  • Добавьте 4 A-записи для вашего домена (с именем @):
    185.199.108.153
    185.199.109.153
    185.199.110.153
    185.199.111.153
  • Добавьте 1 CNAME-запись для поддомена www:
    значение: ваш_логин.github.io. (с точкой на конце)

2. В репозитории GitHub:

  • В репозитории сайта откройте Settings → Pages → Custom domain, введите купленный домен ваш-домен.com и включите галочку Enforce HTTPS.

📥 3. Скачать полную базу данных (.json) на компьютер

Создает единый файл teplica_full_database.json со всеми товарами, ценами, отзывами, выполненными работами и всеми загруженными фотографиями (в Base64).

📤 4. Загрузить базу данных из файла

Выберите ранее сохраненный JSON-файл базы для восстановления товаров и фотографий.
