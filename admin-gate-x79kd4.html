🌐 Привязка домена .com из Reg.ru к GitHub Pages

1. В личном кабинете Reg.ru (DNS-серверы и управление зоной):

  • Добавьте 4 A-записи для домена @:
    185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
  • Добавьте 1 CNAME-запись для поддомена www:
    значение: Punelittley.github.io. (с точкой на конце)

2. В репозитории GitHub:

  • В репозитории сайта откройте Settings → Pages → Custom domain, введите купленный домен и включите Enforce HTTPS.
